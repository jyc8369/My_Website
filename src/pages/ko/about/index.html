좋아하는 것들

안녕하세요, jyc8369입니다.

저는 AI를 활용해 떠오른 아이디어를 실제로 만들어 보는 것을 좋아합니다. 무언가를 만들고 싶다는 생각이 들면, 지금 제 능력으로 가능한 일인지부터 따지기보다 어떤 방법으로 구현할 수 있을지 먼저 고민합니다. 처음부터 모든 것을 알고 시작하는 것은 아니지만, 필요한 것을 하나씩 알아보고 여러 도구의 도움을 받으면서 조금씩 형태를 만들어 가는 과정 자체를 즐깁니다.

제가 가장 관심을 가지고 있는 분야는 AI입니다. AI를 완벽하게 이해하거나 직접 개발할 수 있어야만 활용할 수 있다고 생각하지 않습니다. 지금 사용할 수 있는 기술로 무엇을 해 볼 수 있을지 탐색하고, 새로운 모델과 도구를 제 작업 방식에 어떻게 활용할지 알아보는 데 더 관심이 많습니다. 특히 AI를 실제 개발 과정에 활용하거나 직접 관리하는 환경과 연결하는 일에 흥미를 느낍니다.

AI가 모든 문제를 해결해 준다고 생각하지는 않습니다. 기대한 결과가 나오지 않거나 방향이 어긋날 때도 있습니다. 그런 한계까지 포함해 AI를 어떻게 활용하면 좋을지 알아가는 과정에 관심이 있습니다.

소프트웨어 개발도 좋아합니다. 화면에 보이는 부분보다는 백엔드 시스템이나 API처럼 실제 기능이 동작하는 부분에 더 관심이 있습니다. 사용자의 요청이 내부에서 어떻게 처리되는지, 서로 다른 구성 요소가 어떤 방식으로 연결되는지 알아보는 것을 좋아합니다. 하나의 기능 뒤에 여러 부분이 연결되어 있고, 구조에 따라 동작과 유지 관리 방식이 달라진다는 점도 흥미롭습니다.

서버를 직접 운영하는 것에도 관심이 많습니다. 이미 만들어진 서비스를 사용하는 것도 편리하지만, 가능하다면 직접 설치하고 구성해 제 환경에 맞게 쓰는 방식을 좋아합니다. 직접 운영하면 각 부분이 어떻게 연결되는지 확인할 수 있습니다. 물론 설정과 문제 해결에 손이 더 많이 가기도 하지만, 그 과정에서 시스템을 더 이해하게 됩니다.

서버와 소프트웨어뿐 아니라 하드웨어와 전자기기에도 관심이 있습니다. PC를 조립하거나 부품을 살펴보고, 기기를 분해하거나 간단히 손보는 일을 좋아합니다. 이미 가진 장비가 어떻게 구성되어 있고 각 부분이 어떤 역할을 하는지 알아보는 것만으로도 흥미를 느낍니다. 하드웨어와 소프트웨어 모두 겉으로 보이는 결과 뒤에 여러 구성 요소가 있고, 구조를 이해할수록 더 다양한 시도를 할 수 있다는 공통점이 있습니다.

AI, 소프트웨어, 서버, 하드웨어 중 하나를 특별히 잘한다고 말하기는 어렵습니다. 아직 모르는 것도 많고 직접 해 보지 못한 것도 많습니다. 다만 관심이 생긴 것을 알아보고, 필요한 도구를 찾아 사용하고, 가능하다면 직접 작동하게 만들어 보는 일을 꾸준히 좋아합니다.

저에게 중요한 것은 무언가를 잘 안다고 보여 주는 것보다 궁금했던 것을 직접 시도해 보고, 전에는 할 수 없었던 일을 조금씩 할 수 있게 되는 과정입니다.

제가 중요하게 생각하는 것

저는 제가 사용하는 시스템을 가능하면 직접 이해하고 관리하고 싶습니다. 모든 서비스를 직접 운영해야 한다고 생각하는 것은 아닙니다. 잘 만들어진 외부 서비스를 쓰는 편이 합리적이거나 관리 부담을 줄이는 선택일 때도 있습니다.

제가 직접 운영을 선호하는 이유는 사용하는 시스템에 대한 결정권을 가능한 한 스스로 가지고 싶기 때문입니다. 외부 서비스에서는 기능과 조건, 요금이 제공자에 의해 정해지지만, 직접 운영하면 소프트웨어와 기능, 연결 방식을 제 목적에 맞게 선택할 수 있습니다.

직접 운영에는 책임과 비용도 따릅니다. 설정 오류를 해결하고 시스템을 유지하는 데 시간과 장비 비용이 들며, 언제나 가장 효율적인 방법은 아닙니다. 대신 필요할 때 작동 원리를 살펴보고 원하는 부분을 바꾸거나 문제의 원인을 찾아 해결 방법을 선택할 수 있습니다. 사용량에 따른 비용을 포함해 무엇에 얼마를 쓰는지 파악하고 조정할 수 있는 점도 중요합니다.

직접 운영이 모두에게 맞는 답이라고 생각하지는 않습니다. 제게 중요한 것은 무엇이든 혼자 관리하는 일이 아니라, 필요할 때 선택하고 목적에 맞게 조정하며 계속 사용할지 결정할 수 있는 여지입니다.

AI 활용

저는 대부분의 프로젝트에서 AI를 활용해 코드를 작성합니다. 만들 기능과 원하는 동작을 설명하고, AI가 생성한 코드를 검토한 뒤 필요한 변경을 정합니다. 프로젝트의 코드를 모두 직접 작성했다고 말할 수는 없습니다. 상당 부분을 AI가 만들기도 합니다. 저는 방향을 정하고 결과를 확인하며 실제 목적에 맞도록 수정하고 운영합니다.

특히 프론트엔드 구현은 제게 어려운 부분이라 AI의 도움을 많이 받습니다. 이 사이트도 제가 방향과 주요 결정을 정하고 AI를 활용해 만들고 있습니다. AI를 사용해도 요구 사항을 구체화하고 결과를 검증하는 일은 필요합니다. 코드가 생성되었다고 올바르게 동작하는 것은 아니며, 익숙하지 않은 기술이나 구조는 추가로 알아봅니다.

AI가 만든 코드를 항상 완벽히 이해하는 것은 아니며, 모든 것을 직접 구현했다고 꾸미고 싶지도 않습니다. 모르는 점을 인정하고 배우며 개선하는 것이 제 방식입니다. 제게 AI는 현재의 능력만으로 어려웠을 아이디어를 직접 시도할 수 있게 해 주는 도구입니다.

사용하는 AI 도구와 환경

Codex는 주로 코드 작성과 기능 구현에 활용합니다. 만들고 싶은 기능을 설명하고 결과를 확인하거나 기존 코드를 변경할 때 도움을 받습니다.

자체 로컬 LLM도 사용합니다. 외부 AI 서비스를 이용하는 것뿐 아니라 모델을 직접 운영할 수 있는 환경에도 관심이 있습니다.

자체 MCP 환경을 직접 구성해 AI와 다른 도구 및 기능을 연결해 사용합니다. AI가 텍스트를 생성하는 데서 나아가 필요한 도구와 연결될 수 있다는 점에 흥미를 느낍니다. 현재 별도의 하네스는 사용하지 않습니다.

도구를 많이 쓰는 것 자체가 목적은 아닙니다. 필요한 상황에 맞게 활용해 원하는 결과에 가까워지는 것이 중요합니다. 도구와 활용 방식은 앞으로 달라질 수 있지만, 무엇을 만들지 제가 결정하고 AI가 만든 결과를 실제 목적에 맞는지 확인하며 결과물을 관리 가능한 형태로 유지하고 싶다는 기준은 같습니다.

저에게 AI는 모든 것을 대신해 주는 마법 같은 도구가 아닙니다. 지금 제 능력만으로는 구현하기 어려웠을 아이디어를 실제로 시도할 수 있게 해 주는 도구입니다. AI가 생성한 코드의 도움을 받는다는 사실을 감추고 싶지 않습니다. 그 사실을 인정하면서도 어떤 생각을 하고, 어떤 방향으로 만들며, 무엇을 중요하게 여기는지는 충분히 이야기할 수 있다고 생각합니다.

이 사이트를 만든 이유

이 사이트는 처음부터 명확한 목적을 가지고 계획한 결과물이 아닙니다. 별다른 계획 없이 도메인과 VPS를 충동적으로 구매한 것이 시작이었습니다. 무엇을 만들겠다는 구체적인 목표도, 반드시 개인 웹사이트가 필요했던 것도 아니었습니다. 도메인과 서버가 생긴 뒤에야 이 공간을 어떻게 사용할지 생각하게 되었습니다.

도메인이나 서버를 준비했다고 해서 그 위에 꼭 무언가를 만들어야 하는 것은 아닙니다. 그래도 제 도메인과 서버가 생긴 이상 그대로 두기에는 조금 아쉬웠습니다. 특별한 기능의 서비스를 만들지, 개발 결과물을 정리할지, 단순한 개인 홈페이지로 둘지 고민했습니다.

하지만 특정한 목적을 억지로 정하고 싶지는 않았습니다. 이 사이트를 취업용 포트폴리오나 제 능력을 증명하는 공간으로 만들 생각은 없습니다. 기술을 얼마나 잘 쓰는지 보여 주거나 결과물을 그럴듯하게 포장하기보다, 제가 좋아하는 것과 생각, 시도해 보고 싶은 것을 자연스럽게 남기고 싶었습니다.

처음부터 완성된 계획이나 모든 콘텐츠가 준비되어 있을 필요는 없다고 생각합니다. 지금 관심 있는 것을 소개하고, 직접 쓴 글을 올리고, 새로운 것을 만들고 싶어지면 공간을 조금씩 바꾸면 됩니다. 아직 비어 있는 페이지가 있을 수도 있고 지금의 구성이 나중에 달라질 수도 있습니다. 관심사는 변하고, 사이트도 그에 맞춰 바뀌어 갈 수 있습니다.

이곳을 제가 직접 운영한다는 점도 의미가 있습니다. 다른 서비스의 정해진 형식에 맞춰 자신을 소개하는 대신, 필요한 것을 넣고 마음에 들지 않는 부분은 제 방식대로 바꿀 수 있습니다. 이 점은 직접 시스템을 운영하는 방식을 좋아하는 이유와도 이어집니다.

개인 웹사이트 하나를 운영한다고 해서 대단한 일을 한다고 생각하지는 않습니다. 인터넷에는 수많은 개인 사이트가 있고 이곳도 그중 하나입니다. 그래도 제 도메인에 제가 원하는 구성으로 생각을 담아 둘 작은 공간이 있다는 사실이 마음에 듭니다.

이 사이트가 얼마나 커질지, 어떤 내용을 담을지는 아직 정해져 있지 않습니다. 많은 사람이 방문해야 한다거나 정해진 주기에 맞춰 글과 기능을 추가해야 한다는 부담도 갖고 싶지 않습니다. 필요할 때 글을 쓰고 관심 있는 것을 더하며, 더 나은 구성이 떠오르면 바꾸면 됩니다.

충동적으로 구매한 도메인과 VPS를 어떻게 사용할지 고민하는 데서 시작했지만, 결과적으로는 제가 좋아하는 것들을 제 방식대로 남길 수 있는 공간을 만들게 되었습니다. 이 사이트는 완성된 결과물이라기보다 앞으로도 조금씩 바뀌고 채워질 개인적인 공간입니다.
